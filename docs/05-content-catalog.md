# 内容目录：商品与法律

> 版本 v0.1。这里是**设计目录**：哪些商品、哪些法律、各自的权衡。等消费它们的系统写好时，再逐条变成数据文件——项目原则是不写没人用的数据（见 `CLAUDE.md`），所以目录先写在文档里。
> 以后扩充商品和法律时，**只改数据，不改代码**，具体机制见第 1 节。

---

## 1. 扩展机制：加商品、加法律不用改代码

### 1.1 商品

每种商品是一条数据：

```yaml
id: good.electric_car
name: 商品.电动汽车          # 本地化键
category: consumer_durables
trade: global                # global / regional（如电力）/ local（如住房、本地服务）
base_price: 30000            # 基准价格（不变价核算单位）
needs:                       # 能满足哪些需求类别，以及替代权重
  transport_private: 1.0
tags: [vehicle, electric]    # 系统只通过标签认识商品
storage_half_life_months: 120
carbon_per_unit: 0           # 使用时的碳排放
era: { from_tech: tech.lithium_batteries }
```

模拟代码**从不写死商品 ID**，只通过三种途径接触商品：

1. **配方**：建筑的生产方式写明投入和产出（数据）。
2. **需求类别**：人口按类别消费，类别内部按价格替代（数据）。
3. **标签**：少数机制需要"认识"某类商品，例如成本冲击指数看 `energy` 和 `imported`，经济安全看 `critical`，粮食安全看 `staple_food`。标签的含义在代码中定义并写成文档，新商品复用已有标签即可。

ESLint 会拦截模拟代码里形如 `'good.xxx'` 的字面量，保证这一点。

**新增一种商品的步骤**：写一条商品数据 + 本地化文本 + 图标；至少有一个建筑生产它、至少有一个需求类别或配方消耗它。内容校验（随内容系统一起实现）会检查"没人生产"和"没人消费"的孤儿商品——这正是"没有作用的数据"在内容层面的静态检查。

### 1.2 法律

每个法律组有若干互斥选项，每个选项是一条数据：

```yaml
id: law.central_bank.independent
group: law.central_bank
name: 法律.央行独立
requires: { tech: tech.modern_central_banking }
stances:                     # 各社会力量的态度（−2 到 +2）
  finance: 2
  labor: -1
  bureaucracy: 1
effects:                     # 修正项：只能使用已注册的修正键
  macro.central_bank_independent: 1
  state.capacity_upkeep: 0.5
enactment: { months: 12, state_capacity: 10 }
```

- 效果只能写**已注册的修正键**。修正键注册表列出每个键的含义、单位，以及**由哪个系统读取**。
- 静态检查双向进行：数据里用到的修正键必须已注册且有系统读取；注册了却没有任何数据使用、或没有任何系统读取的键会被报告为无用。
- **新增一个法律选项**：只要它的效果能用现有修正键表达，就只改数据。只有引入全新的机制（新的修正键）时，才需要在读取它的系统里写代码并注册。

## 3. 法律目录（58 组，约 250 个选项）

每组同一时间只能选一个选项。"权衡"一栏写最关键的取舍，详细效果在数据中定义。

### 3.1 经济体制

| 法律组 | 选项 | 关键权衡 |
|---|---|---|
| 经济体制 | 指令计划 / 指导性计划 / 价格双轨 / 混合经济 / 自由市场 | 动员能力 vs 信息问题；见经济模型文档 |
| 所有制 | 全面公有 / 国有主导 / 关键行业国有 / 私有为主 / 全面私有化 | 软预算约束 vs 不平等与外资控制 |
| 农业组织 | 大地产 / 减租减息 / 耕者有其田 / 合作社 / 集体农庄 / 家庭承包 / 农业公司化 | 地主与农民的政治力量；单产与劳动力释放 |
| 价格管理 | 全面定价 / 关键商品定价 / 价格补贴 / 自由价格 | 稳定民生 vs 短缺与财政负担 |
| 竞争政策 | 卡特尔合法 / 无竞争法 / 反垄断 / 严格反垄断（可拆分企业） | 大企业效率与政治力量 vs 创新与消费者 |
| 产业政策 | 无 / 进口替代 / 出口导向 / 战略产业扶持 / 绿色产业政策 | 学习效应与追赶 vs 寻租与资源错配 |
| 外资政策 | 禁止 / 合资与技术转让要求 / 经济特区 / 国民待遇 / 积极招商 | 技术溢出与资本 vs 利润外流与外部筹码 |
| 国企治理 | 行政管理 / 承包经营 / 公司化 / 混合所有制 / 私有化 | 国家控制 vs 效率与腐败 |
