# 开发路线图

> 版本 v0.2：真实世界优先。

## 原则

- **真实世界从一开始就是目标**：世界地图与 1946 年开局数据提前到第二、三个阶段，之后的每个系统都直接跑在真实世界上。
- **先护栏、再功能**：静态分析、规律测试、对抗性审查在写大量代码之前就位。
- **纵向切片**：每个里程碑都有能运行、能验证的成果和明确的完成标准。
- **不写没人用的东西**：商品与法律在消费它们的系统落地时，才从目录变成数据。

**粗略量级**（全职 1—2 人 + AI 辅助的估计，实际取决于投入时间与美术资源）：真实世界优先意味着前期的数据与地图工作更重，第一个可玩版本（M7）大约需要 12—16 个月。

## 下一阶段任务（M2：世界地图）

1. 获取 Natural Earth 1:10m 国家与一级行政区边界（公有领域），用脚本合并或拆分为约 1,200 个地区。
2. 为 1946 年的分界线（德国占领区、朝鲜半岛三八线等）制作手工切分数据。
3. 生成运行时资源：地区 ID 纹理、边界折线、邻接图、标签位置。
4. 地形底图：把公有领域的晕渲地形、分层设色、海深栅格预处理为纹理和法线贴图。
5. WebGL2 渲染器：平移缩放、地区着色、矢量边界、中文标签、地图模式；用 Playwright 截图做视觉回归。
6. 美术：按确认的方向先出少量关键图（界面框架、一组商品图标样张），确认后再批量。

## 项目风险

| 风险 | 对策 |
|---|---|
| 范围失控 | 严格按里程碑推进；每个新系统必须接入核心循环才做；坚守设计文档中的"不做什么" |
| 经济模型调不稳 | 两层结构、有界响应、隐式求解、规律测试、自动校准 |
| 真实数据工作量巨大 | 数据管线 + 自动校准；先保证宏观总量正确，再细化地区 |
| 玩家看不懂 | 因果解释与经济规律图鉴从第一个界面起就内建 |
| 敏感内容与发行合规 | 遵循设计文档第 17 节；地图边界来自可核查的数据，并保留按地区配置的能力 |
| 美术成本 | AI 出图先定风格再批量；地图本身是主要视觉，靠程序化渲染保证质量 |
