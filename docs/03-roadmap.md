# 开发路线图

> 版本 v0.1 · 草案。

## 原则

- **先模拟，后画面**：先做一个能在命令行里跑完 100 年且不崩溃的经济内核，再做界面。
- **纵向切片**：每个里程碑结束时，都有一个能运行、能验证的东西。
- **虚构小国先行**：先在一个约 10 个地区的虚构国家上验证机制，最后才上真实世界地图与 1946 年数据。真实数据是最大的工作量，必须等机制稳定后再投入。

## 里程碑

| 里程碑 | 目标 | 主要内容 | 完成标准 |
|---|---|---|---|
| **M0 工程骨架** | 能跑、能测 | monorepo、TypeScript 严格模式、lint、Vitest、CI、数据 Schema、回合调度器、无头命令行 | `pnpm test` 通过；`pnpm sim --years 10` 输出统计 |
| **M1 经济内核** | 一个会"呼吸"的经济 | 1 个虚构国家、约 10 个地区、约 15 种商品、约 15 种建筑、约 8 种职业；生产、消费、价格、工资、利润、简单财政；因果分解 | 无头跑 100 年不崩溃；资金与人口守恒测试通过；价格收敛；外生技术进步下，农业就业占比随时间下降 |
| **M2 人口与宏观** | 人口转型与经济周期 | 年龄队列、生育与死亡、教育管道、城乡迁移、非正规部门；货币、央行、通胀、利率、国债、简单金融周期 | 人口转型曲线自然出现；赤字货币化会导致通胀；能观察到刘易斯拐点；出现经济周期 |
| **M3 可玩切片** | 一个人能玩的经济沙盒 | Web 界面：地区地图、宏观仪表盘、建筑 / 人口 / 预算 / 法律面板、时间控制、图表、因果解释提示 | 玩家能从 1946 年玩到 2045 年；计划经济与市场经济两条路线的结果明显不同 |
| **M4 政治** | 改革有阻力 | 社会力量、执政联盟、合法性、法律推行、政党与选举、运动、政变、国家能力与腐败 | 改革会遭遇反对；可能发生政权更迭；AI 处理国内政治的表现合理 |
| **M5 多国与外交** | 世界开始运转 | 约 8—12 个国家；自动贸易、汇率与国际收支、援助 / 投资 / 制裁、集团、国际组织、危机升级、抽象冲突；国家 AI 第一版 | 出现贸易依赖与集团；多数危机通过谈判解决；纯 AI 对局能跑完百年 |
| **M6 真实世界 1946** | 真实地图与开局 | 地图管线、1,000 个以上地区、1946 开局数据、殖民地与去殖民化、历史校准测试 | AI 自动运行百年，世界人口、增长、城市化等指标落在历史合理区间 |
| **M7 内容与打磨** | 抢先体验版 | 国家议程与事件、到 2045 年的技术内容、能源与气候、美术与音频、教程、本地化、存档、性能、模组文档 | 外部试玩并收集反馈 |

**粗略量级**（全职 1—2 人 + AI 辅助的估计，实际取决于投入时间与美术资源）：M0—M3 约 3—4 个月，得到可玩的单国经济沙盒；M4—M6 再需要约 8—12 个月；抢先体验版总计约 18—24 个月。M3 的单国经济沙盒本身就可以作为一个早期试玩版。

## 第一阶段任务清单（M0 + M1）

1. 初始化 pnpm monorepo：`packages/sim`、`packages/data`、`packages/shared`、`tools/headless`（`packages/ui` 先留空）。
2. TypeScript 严格模式、ESLint、Prettier、Vitest、GitHub Actions CI。
3. 状态容器（SoA）、实体 ID、带种子的随机数、回合调度器、修正项（因果分解）基础设施。
4. 数据 Schema（商品、建筑、生产方式、职业）与一个虚构国家的最小数据集。
5. 五个系统：生产、劳动力匹配、市场价格、收入分配、消费（LES）。
6. 不变量测试：资金守恒、人口守恒、无 NaN。
7. 无头命令行：跑 N 年，输出 CSV（GDP、价格、就业结构、工资），附一个画图脚本。

## 项目风险

| 风险 | 对策 |
|---|---|
| 范围失控 | 严格按里程碑推进；每个新系统必须接入核心循环才做；坚守设计文档里的"不做什么" |
| 经济模型调不稳 | M1/M2 就建立自动化测试与参数扫描 |
| 真实数据工作量巨大 | 推迟到 M6；用数据管线与自动校准 |
| 玩家看不懂 | 因果解释从 M1 起就内建 |
| 敏感内容 | 遵循设计文档第 17 节的原则 |
| 美术资源 | 早期用程序化 / 极简美术，地图本身就是主要视觉 |
