# 战后百年（暂定名）· Postwar Century

一款以**经济、人口、政治与外交**为核心的大战略模拟游戏，时间跨度 **1946—2045**：从二战后的废墟与帝国残影出发，走过冷战、去殖民化、石油危机、全球化、数字革命、老龄化与气候变化，直到二战结束一百周年。

在核威慑的阴影下，大国之间几乎无法再用全面战争决胜，竞争的战场转移到了**工厂、货币、选票、援助与思想**。所以本作不做前线与部队调度，战争被压缩为危机升级与经济—政治消耗。

灵感来自《维多利亚3》这类以人口与市场为核心的经济模拟大战略；时代、系统与玩法重心是原创设计。

## 当前状态

- 设计文档（见下表）。
- 质量护栏：TypeScript 严格模式、ESLint、Prettier、Knip、自研静态分析、对照测试与属性测试、对抗性审查子代理。
- 宏观经济块原型：通胀、预期与信誉、利率、汇率与储备、本币与外币债务、违约与市场排斥，12 个可运行的场景；规律在标定值附近有测试，参数与政策的整个范围有数值安全测试。
- 美术风格样图（待确认）：`art/style-samples/`。

## 快速开始

需要 Node 22.18 以上与 pnpm。

```bash
pnpm install
pnpm check                 # 全部静态检查与测试
pnpm macro                 # 列出宏观场景
pnpm macro disinflation    # 运行一个场景（按年输出）
pnpm macro disinflation --set credibilityHalfLifeMonths=60   # 临时换参数
pnpm macro --params        # 参数说明：数值、单位、范围、含义
```
